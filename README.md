DESIPAISAKHATA – PRIVACY POLICY
Last Updated: May 2026

1. INTRODUCTION
Welcome to DesiPaisaKhata ("we", "our", or "us"). We operate as an Individual Independent Developer entity. We are deeply committed to protecting your personal data privacy rights. This Privacy Policy outlines exactly how we handle user data parameters for our mobile finance ledger tracking utility software application.

2. DATA WE COLLECT AND WHY
We believe in strict data minimization. The only user infrastructure properties we handle are:
- Email Address: Collected solely during your initial registration setup to uniquely identify your secure premium account profile mapping and handle validation access tokens.
- Expense Ledger Entries: Any numbers, transaction tags, descriptions, or budget calculations you type into the application are compiled and stored safely.

3. DATA STORAGE AND SECURITY
- Local Tracking: All financial entries are cached locally on your physical device memory inside a private, encrypted SQLite storage structure file directory.
- Cloud Synchronization: For verified Premium Tier accounts, data rows are transported securely over encrypted network client channels (HTTPS) and mirrored onto enterprise-grade cloud database servers powered by Microsoft Azure.

4. DATA PRIVACY AND THIRD-PARTY POLICY
- Zero SMS Scraping: Unlike alternative over-engineered financial tools, Desi Paisa Khata does NOT read, scan, or scrape your private mobile network SMS data lines or banking transaction texts.
- Zero Data Selling: Your bookkeeping spreadsheets, registration emails, and tracking analytics are completely private. We never share, trade, rent, or sell your financial ledgers to third-party advertising algorithms.
- Payment Data Safety: All financial transaction routing and subscription processing arrays are driven directly via the Razorpay payment gateway API. We do not store credit card integers or local bank branch passwords.

5. USER CONTROL AND AUTOMATED DELETION RIGHTS
You possess full structural rights over your profile metadata. Desi Paisa Khata provides a fully automated data elimination system to ensure you maintain complete ownership of your ledger. You can trigger a full database wipe execution sequence directly by clicking the "Delete Account" button inside the app settings panel. This action instantly purges your local device history and broadcasts a secure terminal command to completely erase your user profile records from our Azure cloud sync tables in real time.
